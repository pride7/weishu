# 卫戍协议伤害计算器

明日方舟「卫戍协议·规程」的伤害计算器：选阵营、调层数和敌人，给干员换技能、装装备，逐帧模拟每名干员的实际输出。

在线使用：<https://pride7.github.io/weishu/>

## 能做什么

- 10 个核心盟约 + “无核心盟约”视图，共 143 名干员（其中 132 名输出位）
- 高阶干员可切换三个技能，每人 2 格装备，支持“变形同构体”额外获得盟约
- 10 个领袖的属性、各难度生命、能力说明，可设为目标并估算击杀时间
- 输出时间轴、伤害构成、输出随盟约层数变化的曲线

## 计算口径

逐帧（1/30 秒）模拟攻击、技力和技能循环。概率和条件效果取期望值；召唤物、给队友的光环没有计入，元素损伤目前只建模了克莱门莎的侵蚀损伤。
【阿戈尔】的吞噬可以选被吞噬的干员：吞噬者获得它的基础攻击力，并按它的生命和防御判断挨 5000 点伤害后能否存活。
每名干员的具体建模方式和未确认的机制，都写在页面里的“干员详情”和“计算口径与未确认项”中。
这些数字没有和游戏内实测逐一核对，适合横向比较，不能当成精确值。

## 自己构建

页面是一个不依赖任何外部资源的单文件 HTML。

```bash
node build.js
```

会把 `src/` 下的各部分拼成 `index.html`：

| 文件 | 内容 |
|---|---|
| `src/iberia.js`、`src/ops.js`、`src/ops2.js` | 干员数据 |
| `src/skills.js` | 可选技能与装备 |
| `src/stats.js` | 干员的生命与防御（判断被吞噬后能否存活） |
| `src/engine.js` | 盟约公式与模拟引擎 |
| `src/bosses.js` | 领袖资料 |
| `src/notes.js` | 各阵营要点 |
| `src/ui.js`、`src/style.css`、`src/body.html` | 界面 |
| `src/avatars/`、`src/bossimg/` | 干员头像与领袖图片 |

## 数据来源与版权

干员面板、技能、装备与盟约数值来自 [PRTS](https://prts.wiki/w/卫戍协议·规程/PRTS盟约记录) 及其整理的游戏数据（赛季「规程·序列 I」，取于 2026-11-14）。
