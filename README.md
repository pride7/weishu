# 卫戍协议伤害计算器

明日方舟「卫戍协议·规程」的伤害计算器，有两个页面：

- **单人排行**：选阵营、调层数和敌人，给干员换技能、装装备，逐帧模拟每名干员单独打木桩的输出。
- **队伍模拟**：选战场、回合和难度，在真实的格子上摆放最多 8 名干员，按该回合的出怪表模拟整场战斗，看清场用时、漏怪和每人的输出，并逐秒回放。

在线使用：<https://pride7.github.io/weishu/>

## 能做什么

- 10 个核心盟约 + “无核心盟约”视图，共 143 名干员（其中 132 名输出位）
- 高阶干员可切换三个技能，每人 2 格装备，支持“变形同构体”额外获得盟约
- 10 张战场的单人场地（含随机障碍位）、第 1–13 回合的出怪表、16 场领袖战，联合模拟 4 档与独立模拟规程等级 1–20；可以直接在游戏截图上摆放，头像拖到格子上放置，拖动场上干员移动或互换、拖出战场撤下，放下后像游戏里一样拖向一个方向选朝向（双击场上干员可重选）
- 特训敌人：选本局的特训组合和本回合抽到的敌人，按官方规则替换出怪表里的占位敌人
- 敌人技能：光环（加防、加抗、减伤、分摊伤害）、护盾、回复、余烬复活、石像、分裂与召唤、嘲讽，以及对干员的攻速削弱、攻击力削弱、阻挡数削弱、晕眩和缴械；数值取自游戏数据，规则按 PRTS 各敌人页面，可以一键关闭对比
- 干员受击：敌人攻击阻挡者或射程内最后部署的干员，干员会倒下、再部署、被治疗；计入盟约和模组的生存加成，以及敌人的溅射、死亡爆炸、流血、污染等
- 敌人按真实路线行走、被阻挡、被击倒；盟约按在场人数自动激活；元素损伤、麻痹、减防减抗全队共享
- 输出时间轴、伤害构成、输出随盟约层数变化的曲线；队伍模拟的地图回放
- 研究工具：保存多套方案，在第 1–13 回合（和选中的领袖战）上一次跑完并并排对比；把一名干员挪到每个能放的格子试算最佳摆位；复制分享链接还原整套阵容

## 计算口径

逐帧（1/30 秒）模拟攻击、技力和技能循环，攻击间隔按帧对齐。概率和条件效果取期望值；召唤物、给队友的增益光环没有计入，元素损伤（神经、侵蚀、灼燃、凋亡）及其爆发已建模。
队伍模拟里敌人按碰撞箱进入范围、碰到干员即被阻挡，技能按 PRTS《卫戍协议/帮助》的技能操作方案自动释放。敌人技能只计入了与关卡机制无关的部分，领袖技能大多没有计入，详见页面里的“队伍模拟的口径”。
干员数据对照游戏数据（技能、天赋、模组）逐项核对过，并与 ArknightsDpsCompare 的公式抽查对比；同一情境下队伍模拟与单人排行的结果一致。
每名干员的具体建模方式和未确认的机制，都写在页面里的“干员详情”和两个“口径”说明中。
这些数字没有和游戏内实测逐一核对，适合横向比较，不能当成精确值。

## 自己构建

页面是一个不依赖任何外部资源的单文件 HTML。

```bash
node build.js
```

会把 `src/` 下的各部分拼成 `index.html`：

| 文件 | 内容 |
|---|---|
| `src/iberia.js`、`src/ops.js`、`src/ops2.js` | 干员数据与技能模型 |
| `src/skills.js` | 可选技能与装备 |
| `src/stats.js` | 干员的生命与防御（判断被吞噬后能否存活） |
| `src/engine.js` | 盟约公式、干员个体与单人排行的模拟 |
| `src/field.js` | 战场、出怪表、敌人、攻击范围（由 `tools/extract.js` 生成） |
| `src/team.js` | 队伍模拟：行走、阻挡、索敌、共享状态 |
| `src/bosses.js` | 领袖资料 |
| `src/notes.js` | 各阵营要点 |
| `src/ui.js`、`src/team-ui.js`、`src/style.css`、`src/body.html` | 界面 |
| `src/avatars/`、`src/bossimg/` | 干员头像与领袖图片 |
| `src/enemyimg/` | 敌人头像（PRTS，64px WebP） |
| `src/mapimg/` | 战场截图（PRTS 收录的游戏截图，裁剪压缩）和格子在截图上的四角坐标 `quad.json`，由 `tools/mapgrid.py` 按 `tools/map-anchors.json` 里的人工锚点拟合生成 |

`src/field.js` 由游戏数据生成。新赛季需要重新生成时，把 PRTS 的游戏数据（`activity_table`、`character_table`、`skill_table`、`range_table`、`enemy_database`、`char_patch_table`，以及 `levels/activities/act3autochess/` 下的关卡文件）下载到一个目录，再运行：

```bash
node tools/extract.js <游戏数据目录>
```

## 规则参考

特训敌人的替换规则、每回合敌人成长倍率、作战阶段 2 倍速等官方数据里没有直接给出的规则，参考了 [sganggs/Stronghold-Protocol](https://github.com/sganggs/Stronghold-Protocol) 的研究整理（`docs/DATA.md` 与其赛季配置）。本项目按这些规则独立实现，没有使用它的代码；成长倍率表保存在 `tools/enemy-scale.json` 并注明出处。

## 数据来源与版权

干员面板、技能、装备、盟约数值、战场、出怪表与战场截图来自 [PRTS](https://prts.wiki/w/卫戍协议·规程/PRTS盟约记录) 及其整理的游戏数据（赛季「规程·序列 I」，取于 2026-11-15）。

干员头像、敌人与领袖图片、战场截图是《明日方舟》的游戏素材，版权归鹰角网络所有。本项目是玩家自制的非官方工具，与鹰角网络无关。
